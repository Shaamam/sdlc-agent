# Phase 8 — CI loop (Tester triages, Developer fixes)

Read `{SKILL_DIR}/references/personas/tester.md` for triage and `developer.md` for fixes.

Goal: green CI, or a clear handback to the developer. Never weaken the checks to get there.

## Watch

1. Get the pushed commit: `git rev-parse HEAD`.
2. Start the watcher **in the background** (Bash with `run_in_background: true`) and wait for the completion notification. Don't poll it.
   ```
   "{PY}" "{SKILL_DIR}/scripts/ci_watch.py" --pr <number> --expect-sha <sha> --ticket {KEY} --timeout-minutes <ci.timeout_minutes>
   ```
   Print one line while waiting: `▸ {KEY} · ci · watching checks on #<number>`.
3. Read its JSON result:
   - `passed` or `no_checks` → **Done** below.
   - `failed` → **Triage**.
   - `timeout` → tell the developer which checks are still pending, then `{STATE} status {KEY} blocked --reason "ci timeout"` and stop. Re-running `/ship {KEY}` resumes the watch.
   - `error` → show the detail and stop the same way.

## Triage (before touching any code)

For each failed check:
```
gh run view <run_id> --log-failed            # read the tail; pipe through tail -n 200 if huge
```
Sort it into exactly one class:

| Class | Evidence | Action |
|---|---|---|
| **ours** | failure points at code or tests this branch changed, or behavior the spec changed | fix it (below) |
| **flaky** | unrelated to the diff, passes locally, timing/network/order-dependent | `{STATE} ci-rerun {KEY} "<check name>"`; if `allowed`, `gh run rerun <run_id> --failed`, then watch again. If not allowed (already rerun once), treat as **infra**. |
| **broken on base** | same check failing on the base branch: `gh run list --branch <base> --workflow "<workflow>" --limit 3 --json conclusion,headSha` | don't fix. Note it in the PR body under "Noticed, not changed" and tell the developer. |
| **infra** | runner, quota, missing secret, service outage, permissions | hand back to the developer with the log excerpt |

Record each one: `{STATE} event {KEY} ci_triage --data '{"check": "...", "class": "ours|flaky|base|infra", "why": "..."}'`

## Fix (class "ours")

1. `{STATE} ci-attempt {KEY}`. If `allowed` is false, you've used all attempts: go to **Hand back**.
2. Reproduce locally with the narrowest command you can. Fix the code (or a test that is genuinely wrong per the spec). Run the full test and lint commands.
3. Commit `fix({KEY}): <what CI caught>` and `git push`. Record `{STATE} event {KEY} ci_fix_pushed --data '{"attempt": <n>}'`.
4. Back to **Watch**.

Forbidden here (and blocked by the guard hook): editing `.github/workflows/`, skipping or deleting tests, loosening assertions just to pass, `--no-verify`, force push.

## Hand back

When attempts run out, or a check is infra or base-broken and blocks the PR:
- tell the developer, per failing check: class, the evidence (a short log excerpt) and what you tried;
- `{STATE} status {KEY} blocked --reason "<one line>"`; stop.

## Done

CI is green (or the repo has no checks). Read `09-awaiting-review.md`. The run isn't over until the PR is merged.
